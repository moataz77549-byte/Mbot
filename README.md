# AI Offer Radar / رادار عروض الذكاء الاصطناعي

Telegram Serverless bot and Mini App for multilingual public AI offers, plus a scheduled collector and Arabic/English daily digest.

**Deployment:** Requires `TGCLOUD_TOKEN` for Telegram Serverless and `TELEGRAM_BOT_TOKEN` + `TELEGRAM_AR_CHAT_ID` for channel broadcasting, stored in GitHub Actions Secrets. Never commit credentials.

The repository is under active setup. See the bundled release for full project files and usage instructions.
